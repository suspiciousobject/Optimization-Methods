Этот проект реализует решение игровой головоломки **«Bird Sort Puzzle»**, в рамках курса «Методы оптимизации». 

# Первый этап. Необходимое условие решаемости

### Цель

Автоматически определять, какие из входных файлов **нерешаемы** («плохие»), и записывать результат в лог.

## 💡 Постановка задачи

Игровое поле состоит из вертикальных колонок, заполненных птицами (обозначаются заглавными латинскими буквами `A–Z`). Несколько колонок изначально пусты и служат буфером.

**Правила перемещения:**
- Перемещать можно только **верхнюю** птицу из колонки.
- Птицу можно положить:
  - в **пустую** колонку, или
  - на птицу **того же вида** (при условии, что колонка не заполнена).
- Запрещено перемещать птицу в полностью заполненную колонку.

**Задача решена**, когда:
- Каждая непустая колонка содержит **только птиц одного вида** и **полностью заполнена**.

**На данном этапе** требуется не найти решение, а **проверить необходимое условие решаемости**:

> [!IMPORTANT]
> Для каждого вида птиц общее количество должно быть **кратно длине колонки** `N`.\
> Если это условие нарушено — файл считается **«плохим»**.

## 🚀 Подход к реализации
Вместо попытки перебора всех возможных ходов (что привело бы к экспоненциальному взрыву), мы применяем **аналитическую проверку**:

1. **Парсим входной файл** (`DATA`-блок), извлекаем все колонки.
2. **Вычисляем длину колонки** `N` — длина первой непустой колонки.
3. **Проверяем**, что все непустые колонки имеют длину `N`.
4. **Подсчитываем** количество птиц каждого вида.
5. **Для каждого вида** проверяем: `count % N == 0`.
6. Если хотя бы для одного вида условие нарушено — файл помечается как `BAD`.

Этот подход **гарантированно** находит все заведомо нерешаемые файлы.

## ⚡ Оптимизация

Программа разработана на **C++** и оптимизирована для **максимальной скорости и минимального потребления памяти**:

- **Без перебора**: нет DFS/BFS/IDA*, что исключает экспоненциальный рост.
- **Линейная сложность**: `O(общее число птиц)` — один проход по файлу.
- **Минимальное использование памяти**:
  - Подсчёт видов — через массив `int count[26]` вместо `std::unordered_map`.
  - Избегаем копирования строк.
- **Использование `-O3 -march=native -flto`** при компиляции.
- **Быстрый ввод/вывод**: `ios_base::sync_with_stdio(false); cin.tie(nullptr);`.
